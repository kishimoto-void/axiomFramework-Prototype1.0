# Prototype 1.0 — Specification (outline)

## Goal

Deliver a runnable path: **Input → Difference Report**

## Non-goals

- Majority-vote multi-LLM
- Semantic correctness of annotations
- Guaranteed convergence
- Production PLP v1.1.3 replacement

## Versioning

- Payload version enters the hash
- Implementation (crate) version does not
- Breaking observation behavior ⇒ version bump + new Golden
